### useRef wala ---->>>>
1. ismai hum kya krenge ki pehle  saare inputs ke liye  ** "null" ** references bnaa lenge , fir unn references ko attach 
   krdenge with jo bhi unka input hoga 

2. then hum form ko submit hone se rokenge , uske liye hum ek function chalayenge , jo ki onSubmit pe chlega form mai 
   usmai esa hota h ki --
   jab hum onSubmit kr rhe h mtlb ki submit kr rhe h mtlb ki koi event chal rha hai 
   toh uss event ko hum as a input lete hai ek humare function ke liye 
   and then hum event.preventDefault() chala dete hai 
3. fir hum data ko access kr skte hai with the help of -->>
    console.log(name , age);  //Yeh current krke property return krte h 
    console.log(name.current , age.current); //Yeh field return krte hai 
    console.log(name.current.value , age.current.value); //Yeh uss field ki exact value kya hai voh return krte hai




### controlledComponents wala ---->>
1.  ismai hum kya krenge ki pehle  saare inputs ke liye  ** "" ** blank feild ke useStates bnaa lenge , fir unn states ki
    destructuring krenge 

2. then hum form ko submit hone se rokenge , uske liye hum ek function chalayenge , jo ki onChange pe chlega form mai 
   usmai esa hota h ki --
   jab hum onChange kr rhe h mtlb ki change kr rhe h mtlb ki koi changes chal rhe hai fields mai
   toh uss event ko hum as a input lete hai ek humare function ke liye 
   and then hum event.target.value chala dete hai 
3. fir hum data ko access kr skte hai with the help of -->>
    console.log(event); 
    console.log(event.target); //Yeh field return krte hai 
    console.log(event.target.value); //Yeh uss field ki exact value kya hai voh return krte hai
    toh fir hum humara function kuch esa bnaayenge 
    onchange = { (event) => setVal( { name : event.target.value } ) }
